# 데빌 커넥션 비공식 한글 번역 패치

본 한글 패치와 패치 프로그램은 **Nyabi**가 제작했습니다.

## 프로젝트 연혁

본 프로젝트는 Nyabi가 제작한 뒤 한동안 번역팀 **글냥이**에 이관되어 관리되었으며, 현재는 다시 원저작자 Nyabi가 직접 관리하고 있습니다.

번역된 **이미지는 토니**님, 번역된 **영상은 민버드**님께서 작업하셨으며, 사용을 흔쾌히 허락해주셨습니다. 이관 기간 동안 참여해주신 Oatone님과 체퓨님께도 감사드립니다.

팀 글냥이는 치지직 스트리머 **여까**님의 커뮤니티 구성원들이 함께 참여한 비공식 팬 번역팀입니다.

본 프로젝트는 개인 팬 활동의 일환으로 자발적으로 진행된 비공식 한국어 번역 작업입니다.

> **면책 조항**
>
> - 본 프로젝트는 **비공식 팬 번역**으로, 원작자 및 배급사와 어떠한 제휴·승인 관계도 없습니다.
> - 본 프로젝트는 게임 본편 또는 이를 대체할 수 있는 데이터를 제공하지 않습니다.
> - 배포되는 파일은 번역 적용을 위한 수정 데이터에 한정되며 단독으로 실행될 수 없습니다.
> - 패치를 사용하려면 사용자가 별도로 정품 게임을 보유하고 있어야 합니다.
> - 원본 게임의 저작권 및 모든 권리는 해당 권리자에게 있습니다.
> - 본 번역물은 원작의 파생 저작물에 해당하며, 원작의 이용 약관 및 관련 법률의 적용을 받을 수 있습니다.
> - 본 번역의 사용으로 발생하는 문제에 대한 책임은 사용자에게 있습니다.

## 설치 방법

1. GitHub 페이지 상단의 **[Releases](../../releases)** 탭으로 이동합니다.
2. 최신 릴리즈에서 본인의 운영체제에 맞는 패치 프로그램을 다운로드합니다.
   - Windows: `DevilConnection-KR-v0.1.2.exe`
   - macOS: `DevilConnection-KR-v0.1.2.zip`
   - Linux: `DevilConnection-KR-v0.1.2.AppImage`
   - 파일 이름의 `v0.1.2` 부분은 릴리즈 버전에 따라 달라집니다.
3. 다운로드한 프로그램을 실행하고 안내에 따라 진행합니다.
   - macOS: 압축을 풀면 `DevilConnection-KR.app`이 나옵니다.
   - Linux: 실행 권한을 부여해야 합니다: `chmod +x DevilConnection-KR-v0.1.2.AppImage`
4. 게임을 실행하면 한글 번역이 적용됩니다!

번역 데이터는 패치 프로그램 안에 들어 있습니다. 별도의 데이터 폴더를 함께 받거나 압축을 풀어 둘 필요가 없으며, 프로그램 파일 하나만 있으면 됩니다.

패치 전 원본 `app.asar`은 자동으로 백업되며, 프로그램의 **되돌리기**를 누르면 언제든 원래 상태로 복구할 수 있습니다.

## 주의사항

- 게임 업데이트 시 수정 사항이 초기화될 수 있습니다.
- 원본 파일은 반드시 백업해두세요.
- 본 번역 패치 사용으로 인한 게임 오류나 문제는 책임지지 않습니다.
- macOS에서 게임 실행 시 보안 경고가 나타날 수 있습니다. 시스템 설정 > 개인정보 보호 및 보안에서 허용해주세요.
- 패치 프로그램에는 코드 서명이 없습니다. 실행 시 Windows에서는 SmartScreen 경고가, macOS에서는 개발자를 확인할 수 없다는 경고가 나타납니다.
  - Windows: **추가 정보** > **실행**
  - macOS: 프로그램을 **우클릭 후 열기**를 선택한 뒤 다시 한 번 **열기**

번역된 **이미지는 토니**님, 번역된 **영상은 민버드**님의 저작물입니다.
해당 저작물의 저작권은 각 권리자에게 있으며 위 라이선스의 적용을 받지 않습니다.

본 프로젝트는 각 권리자의 허락을 받아 이를 포함하고 있을 뿐이며 권리를 주장하지 않습니다.
본 프로젝트 밖에서 이용하시려면 해당 권리자에게 직접 허락을 받으셔야 합니다.

### 서체(폰트) 사용 안내

본 프로젝트는 가독성 향상을 위해 각 권리자가 별도로 배포하는 서체 파일들을 포함하고 있습니다.

각 서체의 저작권은 해당 권리자에게 있으며 본 프로젝트는 서체의 소유권을 주장하지 않습니다.
서체의 사용 조건은 각 권리자가 제공하는 이용 약관 및 라이선스를 따릅니다.

각 서체의 저작권 고지 및 라이선스 전문은
`THIRD_PARTY_LICENSES/fonts` 폴더에서 확인하실 수 있습니다.
